# Ролик ШЕКАРЫ

Анимация собрана кодом на [Remotion](https://www.remotion.dev) (React → MP4). Две версии: полная (2-3 минуты) и короткая (60 секунд) для начала защиты. Текст и разбивка по сценам: [`script_ru.md`](script_ru.md).

## Запуск

```powershell
cd D:\shekara\video
npm install          # один раз
npm run studio       # редактор в браузере: смотреть и листать сцены покадрово
npm run full         # out/shekara_full.mp4
npm run short        # out/shekara_60s.mp4
```

## Устройство

```
src/
  Root.tsx       две версии ролика; длительность сцен считается по записям голоса
  Video.tsx      сцены друг за другом + голос каждой сцены
  timeline.ts    порядок сцен в полной и короткой версии, оценки длительности
  theme.ts       цвета и шрифты (как в презентации)
  ui.tsx         общие элементы: фон, заголовки, банк, монета, конверт, замок
  scenes/        по файлу на сцену: Hook, Chain, Unsolved, Idea, Caught, Results, Product, Finale
public/
  stand/         скриншоты публичного стенда (запасной материал; сцена «Работающий продукт» рисует интерфейс сама)
  voice/         записи голоса 01.m4a … 08.m4a, 06s.m4a, 07s.m4a (в git не попадают)
```

Длительность сцены = длина записи + 0,6 с. Пока записи нет, берётся оценка из `timeline.ts`, поэтому ролик можно смотреть и без голоса.

Стиль: векторная иллюстрация в 2,5D; сцена «Работающий продукт» в стиле SaaS/UI: интерфейс стенда в светлой теме, курсор, клик, смена состояния, подписи как на настоящем стенде. Цифры в сцене «Результаты» взяты из `docs/submission/numbers.md` (третья версия эксперимента). Тексты на экране без длинного тире.
