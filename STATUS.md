# Статус проекта ШЕКАРА

Этот файл — для новой сессии Claude Code (или для себя через неделю). Прочитай его целиком,
потом `docs/SHEKARA.md` (полное решение) и продолжай с раздела «Что делать дальше».

## Контекст, который важно знать сразу

- **Сегодняшняя дата важнее даты в документах.** `docs/SHEKARA.md` писался 3 октября 2026 и
  весь план по дням (разделы 4.5а/4.5б) расписан от этой даты. **Сверь с реальной сегодняшней
  датой** и, если прошло больше пары дней, пересчитай план: подача в Оргкомитет — **20 октября
  2026**, заморозка кода — за 5 дней до внутреннего срока вуза (правило в 4.5в), финал — 10 или
  13 ноября 2026. Не следуй датам из 4.5а/4.5б буквально, если они уже в прошлом.
- **Состав:** 1–2 человека, студенты, своей командой вчетвером (как в первом черновике KARAVAN)
  это не делается — тот вариант отклонён.
- **Почему именно ШЕКАРА, а не KARAVAN.** Это был уже второй прогон арены (100-агентного
  турнира). Первый дал KARAVAN (неттинг-движок для банковской группы) — он не проходил по
  реальному регламенту конкурса АБРК (нужна команда из 4, 48 часов, нет данных банковской
  группы у студента). Второй прогон на реальных правилах конкурса (жюри: банки, НБК, АБР, ЕБРР,
  МФЦА, эксперты AI/кибербез; 1–2 автора; AI-треки в игре) выбрал ШЕКАРА и в финальной проверке
  победил старый вариант 81:42. Решение собрано из 32 конкурентов за 5 раундов атак/защиты.
- **Среда (Windows):** `python3`/`python` могут не работать (заглушки Microsoft Store) — вызывай
  `py`. `gh` CLI не установлен — репозиторий на GitHub создавался вручную через веб. Доступа к
  Kaggle у Claude нет: датасет AMLworld может скачать только человек через `kaggle.json`
  (инструкция в README.md).
- **Репозиторий:** https://github.com/Falconwu17/shekara — уже запушен коммит с README,
  `.gitignore`, `docs/SHEKARA.md`. Работай строго в одной локальной копии (`D:\shekara`), не
  плоди дублей клона — уже была путаница с `C:\Users\Сагир\shekara`.

Открой терминал в этом окне VS Code (папка должна быть `D:\shekara`, не дубль) и запусти:

```

```

Затем напиши что-то вроде: «Прочитай STATUS.md и docs/SHEKARA.md и продолжи с пункта
"Что делать дальше"». Новая сессия подхватит весь контекст из этого файла.
