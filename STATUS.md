## Коротко о проекте

Банк передаёт соседу не данные клиента, а **одну оценку риска счёта** и только **по ссылке на реальный, уже зачисленный перевод**. Каждое обращение пишется в журнал хаба на хэш-цепочке с подписью Ed25519. Уровень раскрытия (L1 — один балл с шумом, L2 — вектор с шумом, L3 — вектор без шума) выбирает регулятор.

Данные — IBM AMLworld HI-Small: 5,08 млн переводов, 30 банков-участников. Обучение на днях 1–6.09, валидация на 7.09, тест на 8–10.09. Разбиение зафиксировано в `data/split_decision.json` до обучения.

## Итоги эксперимента (окончательные, модель больше не трогаем)

PR-AUC на межбанковских переводах с участником, 519 положительных в тесте, 3 запуска:

| Режим | PR-AUC | F1 |
|---|---|---|
| Центральный оператор (подход MITS) | 0,162 | 0,25 |
| Общий граф участников | 0,210 | 0,27 |
| Изолированный банк | 0,315 | 0,39 |
| ШЕКАРА L1 / L2 / **L3** | 0,33 / 0,344 / **0,354** | — / — / **0,41** |

1. **Значимо:** модели на графе банка сильнее центрального оператора, F1 +0,18, парный бутстреп значим в 3 из 3 запусков.
2. **Не значимо:** обмен даёт +12% к изоляции во всех запусках, но бутстреп этого не подтверждает. Около половины прироста — сочетание двух моделей банка (контроль с выпуском-шумом даёт 0,332).
3. **Цена приватности:** L1 по качеству не отличается от шума, польза появляется только у L2/L3.
4. **Удержание денег:** ≈ 8% звеньев в сжатом времени, ≈ 30% с задержкой исходящих (H1).
5. **Скорость:** проверка при зачислении — 0,7 мс. Чек-лист 6.7: пройдено 22 из 22.

По критериям раздела 4.7 это «слабый результат» по приросту от обмена. Подаём честно, сильная сторона — превосходство над центральным оператором и измеренная цена приватности.

## Среда и подводные камни

- Windows, всё на диске D. Python — только `.venv\Scripts\python` (системный `python` может быть заглушкой Microsoft Store). `make` нет — команды из `Makefile` запускать напрямую.
- GPU AMD RX 6600 с PyTorch на Windows не работает — всё на CPU.
- Папка `trace/` совпадает по имени со стандартным модулем Python — запускать из корня через `-m`.
- Локальный стенд: `.venv\Scripts\python -m online.api` → http://127.0.0.1:8000. Docker-контейнеры проекта (`docker compose`) после перезагрузки могут подняться сами со старым образом и занять порт 8000 — остановить: `docker compose stop`.
- `deploy/.env` с ключами в git не попадает. Корпоративный ноутбук для проекта не использовать.
- Скрипты и конфиги сервера хранятся с переводами строк LF (`.gitattributes`).
