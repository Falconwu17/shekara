# Материалы для подачи

Конкурс АБРК 2026, раздел 8 положения. Подаёт вуз: оргкомитет принимает только работу-победителя внутривузовского отбора за подписью ректора (ответ оргкомитета, октябрь 2026). Почта info@abrk.kz, финал 13.11.2026 в Астане (Назарбаев Университет).

## Что отправляется

| Пункт положения | Файл | Как собрать |
|---|---|---|
| 0. Письмо ректора о победителе внутривузовского отбора | скан с ЭЦП (№8/13-918/С-Ш от 19.10.2026), выдаёт вуз | |
| 1. Заявка от ОВПО | `application_ru.docx`, подпись и печать вуза | `python -m docs.submission.application` |
| 2. Резюме RU и EN, по 1 странице | `resume_ru.docx`, `resume_en.docx`, подпись руководителя | `python -m docs.submission.resume` |
| One-pager, 1 страница | `one_pager_ru.docx` / `.pdf` | `python -m docs.submission.one_pager` |
| Pitch-deck, 12 слайдов | PDF, экспорт из презентации | |
| Доклад к презентации, около 6 минут | `doklad_ru.docx` / `.pdf` | `python -m docs.submission.to_docx` |
| Техническое приложение | `tech_appendix_ru.docx` / `.pdf` | `python -m docs.submission.appendix`, затем `python -m docs.submission.to_docx` |
| Демо | https://shekara.21restobar.kz | работает в интернете, обновляется по ссылке |

Готовые `.docx` и `.pdf` в git не попадают (`.gitignore`): их собирают командами выше. PDF делается из Word: «Файл → Сохранить как → PDF». Личные данные участника для заявки берутся из `application_private.json`, этот файл тоже не в git.

## Что не отправляется

| Файл | Зачем нужен |
|---|---|
| `qa_ru.md` | заготовки ответов на вопросы жюри (10 минут Q&A на защите) |
| `numbers.md` | сводка всех цифр с источниками: сверять документы и слайды |
| `annotation_ru.md`, `summary_en.md` | полные аннотации; в заявку идут сокращённые резюме |
| `one_pager_ru.md`, `tech_appendix_ru.md` | исходный текст: из него собираются документы |
| `build.py`, `appendix.py` | генерация текстов и таблиц из `experiments/results` |

## Правила оформления

- Без длинного тире: вместо него точка, двоеточие или перестроенная фраза; диапазоны через дефис (0,315-0,354).
- Цифры берутся только из `experiments/results` через `build.py` и `appendix.py`, вручную не правятся.
- Резюме и one-pager строго на одну страницу: после правки текста проверить PDF.
