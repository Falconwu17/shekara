# ШЕКАРА — одна страница

**1. Проблема.** Деньги жертвы социальной инженерии за минуты проходят через 3–5 счетов-дропов в разных банках; каждый банк видит одно звено. 2024 год (МВД): более 17 тыс. случаев интернет-мошенничества, ≈ 45 млрд ₸ ущерба, возвращено ≈ 2 млрд ₸. Антифрод-центр НБК (с июля 2024) больше всего перехватывает на стороне банка-отправителя — именно там ШЕКАРА даёт наибольший прирост. На бенчмарке AMLworld: один банк видит 28% схемы, 98% переводов отмывания пересекают границу банков, в 82% схем участвуют счета, уже бывшие в межбанковских переводах.

**2. Для кого.** Антифрод- и AML-подразделения банков второго уровня; оператор межбанковского обмена (антифрод-центр НБК); далее МФО через ГКБ.

**3. Решение.** «Не данные, а одна оценка риска прямого контрагента реального перевода». Ночью банк рассылает выпуски о своих счетах только банкам, с которыми у счёта были зачисленные переводы; при зачислении банк-получатель за 0,7 мс проверяет перевод по своему графу и выпускам соседей; подозрительная цепочка трассируется по следующим банкам только по ссылкам на переводы. Полную цепочку видит только оператор.

**4. Ценность (измерено на AMLworld, 3 запуска).** Модель на графе самого банка значимо сильнее центрального оператора межбанковских потоков (подход MITS): PR-AUC 0,315 против 0,162. Обмен оценками добавляет ещё 13% PR-AUC (0,315 → 0,354) во всех запусках, но при 30 банках из 30 тыс. прирост пока не значим; польза есть при векторном выпуске (L2/L3), один балл (L1) не помогает — это цена приватности, которую выбирает регулятор. Клиентские записи не покидают банк; проверка при зачислении — 0,7 мс; 22 автоматические проверки пройдены.

**5. Новизна.** В мире есть центральный граф потоков у оператора платёжной системы (Mastercard/Vocalink MITS) и обмен записями о клиентах (COSMIC в Сингапуре, TMNL в Нидерландах). ШЕКАРА проверяет третий путь для Казахстана: оценка риска только по ссылке на реальный перевод, данные остаются в банке, сравнение с подходом MITS и общим графом на одном бенчмарке, измеренная цена раскрытия в качестве и в ε.
